⚠️ One important thing about database.db

There's one thing I want you to understand before you start.

Your SQL files are naturally suited to Git:

01_create.sql
02_insert.sql
03_update.sql

But database.db is a binary database file.

Git can store it, but Git isn't really designed to track every tiny change inside a binary database.

So I recommend using both:

database.db

for your current working database,

and:

sql/
├── 01_create.sql
├── 02_insert.sql
├── 03_update.sql
└── 04_queries.sql

for your SQL history.

For example:

-- 01_create.sql


CREATE TABLE students (
    student_id INTEGER PRIMARY KEY,
    name TEXT,
    age INTEGER,
    course TEXT,
    marks INTEGER
);

Then:

-- 02_insert.sql


INSERT INTO students VALUES
(1, 'Rahul', 20, 'BCA', 85),
(2, 'Priya', 21, 'BSc', 91),
(3, 'Amit', 19, 'BCA', 76);

Then:

-- 03_update.sql


UPDATE students
SET marks = 95
WHERE student_id = 1;

This is much better for learning, because you'll eventually have a GitHub history of all the SQL you've written.
